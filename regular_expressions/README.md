# Regular Expressions

Ruby scripts that use regular expressions (Oniguruma) to match patterns in a given argument.

## Files

- `0-simply_match_school.rb`: matches the word `School`
- `1-repetition_token_0.rb`: matches `hbtn` with 2 to 5 `t` characters
- `2-repetition_token_1.rb`: matches `htn` and `hbtn`
- `3-repetition_token_2.rb`: matches `hbtn` with one or more `t` characters
